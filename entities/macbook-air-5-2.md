# MacBook Air 5,2 (Mid-2012)

## Hardware Specs

| Component | Details |
|-----------|---------|
| CPU | Intel i5-3427U (Ivy Bridge, dual-core, HT) |
| GPU | Intel HD 4000 |
| WiFi | Broadcom BCM43224 (14e4:4353) |
| Battery | bq20z451 (7200 mAh design, ~85% health) |
| Display | 1440x900 13.3" |
| Storage | SSD (replaceable) |
